
# Работа с анкетами — выгрузка файлов и рассылка

Десктопное приложение на PyQt5 для работы с Excel-таблицами (выгрузки
анкет из Яндекс.Форм: ФИО, телефон, научный руководитель, направление,
ссылки на файлы) и рассылки писем.

```bash


!!!!!!!!!!!!ВАЖНО!!!!!!!!!!!
Для корректной работы приложения
необходимо войти и быть залогиненым в использующейся аккаунт яндекса в браузере


```


## Установка

```bash
pip install -r requirements.txt
```

Требуется Python 3.8+.

## Запуск

```bash
python main.py
```

## Как это работает

### Таблица

Первая строка таблицы .xlsx считается строкой заголовков. Порядок и
состав столбцов может быть любым — везде, где нужен конкретный столбец
(ФИО, направление, ссылки, почта), в интерфейсе показывается выпадающий
список вида «B — Направление работы (Программирование)», где буква —
столбец, текст — заголовок, в скобках — пример значения из первой
строки данных. Так можно понять, что где лежит, даже если заголовков нет.

### 1. Автоматическая выгрузка

1. Открыть таблицу (кнопка вверху окна).
2. Выбрать папку, куда сохранять результат — внутри неё будет создана
   папка `выгрузка`.
3. Выбрать столбец «Направление работы» (столбец ФИО берётся автоматически
   как первый столбец таблицы — A).
4. Нажать «Начать выгрузку».

Для каждой строки создаётся `выгрузка/Направление/ФИО/`. Все ячейки
строки (кроме ФИО и направления), значение которых начинается с `http`,
считаются ссылками на файлы и скачиваются в эту папку. Имя файла — случайное,
до 8 символов, расширение файла сохраняется таким же, как у исходного.
После обработки каждой строки выводится «Успешно», по завершении всей
таблицы — итоговое сообщение с числом успешно обработанных строк.

### 2. Ручной выбор

1. Открыть таблицу.
2. Выбрать столбец ФИО и столбец направления вручную.
3. Кнопкой «Добавить колонку файла…» добавить любое количество пар
   «столбец со ссылкой → имя, под которым сохранить файл» (например,
   `E -> Диплом`, `F -> Согласие на обработку`).
4. Выбрать папку выгрузки и нажать «Начать выгрузку».

Сохраняются только те столбцы, что указаны в списке, под заданными
именами (с сохранением исходного расширения), в той же структуре
`выгрузка/Направление/ФИО/`.

### 3. Список / Рассылка

- Показывается таблица ФИО (столбец A) и выбранного столбца направления.
- Клик по строке (в любом месте) выделяет/снимает выделение — как выбор
  сообщений для пересылки в мессенджере. Есть кнопки «Выбрать всё» и
  «Снять выделение».
- «Удалить выбранные» — удаляет отмеченные строки из таблицы и сохраняет
  изменения в исходный файл.
- «Написать письмо выбранным» — открывает окно с темой, текстом письма
  и возможностью прикрепить файлы; нужно указать столбец с адресами
  почты получателей.

Для отправки писем нужны токен и адрес почты — окно настроек открывается
кнопкой «Токен и почта…» в окне письма или кнопкой «⚙ Аккаунт Яндекса» в
правом верхнем углу главного окна. Вся рассылка идёт через одно
SMTP-соединение; если сервер его разорвёт, программа один раз
переподключится и продолжит. Письма с неверным адресом получателя
пропускаются и отмечаются в журнале, остальные уходят как обычно.

## Аккаунт Яндекса и токен (настраивается один раз)

Вход по логину и паролю из программы убран. Вся аутентификация — по
**одному OAuth-токену Яндекса**, который используется и для скачивания
файлов из Яндекс.Форм, и для отправки писем по SMTP.

Кнопка **«⚙ Аккаунт Яндекса»** в углу главного окна открывает небольшое
(и свободно растягиваемое) окно с двумя полями:

1. **Токен** — OAuth-токен Яндекса.
2. **Почта** — адрес того аккаунта, для которого выдан токен (адрес
   отправителя). Нужен только для рассылки: протокол входа по токену
   (XOAUTH2) требует передавать вместе с токеном адрес почты. Для
   скачивания файлов достаточно одного токена.

### Как получить токен

1. Откройте https://oauth.yandex.ru/client/new/ и создайте приложение:
   платформа «Веб-сервисы», Redirect URI — `https://oauth.yandex.ru/verification_code`.
2. В разделе «Доступ к данным» отметьте права:
   - «Отправка писем через Яндекс.Почту по протоколу SMTP» (`mail:smtp`) —
     для рассылки;
   - права на чтение Яндекс.Форм — для скачивания файлов из анкет.
3. Скопируйте ClientID приложения и откройте в браузере, войдя в нужный
   аккаунт Яндекса:
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>`
4. Токен появится в адресной строке/на странице — вставьте его в поле «Токен».

Если токен выдан только с одним из прав, работать будет только эта часть
(например, файлы скачиваются, а рассылка отвечает ошибкой 535 — или
наоборот).

После нажатия «Сохранить и проверить» значения:
- пишутся в файл `~/.excel_manager/config.json` (токен — в закодированном
  виде, это не полноценное шифрование, а защита от случайного просмотра;
  права на файл ограничиваются владельцем);
- при следующем запуске подставляются автоматически, и приложение само,
  в фоне, проверяет вход в почту по токену.

Статус справа от кнопки в главном окне показывает, выполнен ли вход в
почту и указан ли токен.

### Где это в коде

- Скачивание файлов и место, где в запрос добавляется токен —
  `core/file_manager.py`, функция `download_file` (заголовок
  `Authorization: OAuth <токен>`).
- Вход в почту по токену — `core/mail_sender.py`, метод
  `YandexMailSender._open_connection` (SMTP `AUTH XOAUTH2`); проверка
  токена — `login`; отправка — `open_session` / `send` / `close_session`.
- Проверка токена при запуске — `ui/workers.py`, класс `AutoLoginWorker`,
  запускается из `ui/main_window.py`. Рассылка — `MailSendWorker` там же.
